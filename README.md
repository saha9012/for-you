# Birthday site — for you

Тёмный праздничный React-сайт с салютом, вопросом «ты меня любишь?» и космической мини-игрой.

## Запуск

```bash
npm install
npm run dev
```

## Персонализация

Открой `src/config.ts` и поменяй:

- `HER_NAME` — её имя
- `FINALE.lines` — личное поздравление
- `GAME.targetScore` — сложность (сколько сигналов собрать)
